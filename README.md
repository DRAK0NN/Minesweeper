MINESWEEPER://TRAINER

Офлайн-веб тренажёр Сапёра с терминальным интерфейсом.

Запуск на NixOS:
  cd minesweeper_cli_trainer
  xdg-open index.html

Или через локальный сервер:
  python3 -m http.server 8080
  # затем открыть http://localhost:8080

Управление:
  ЛКМ — открыть
  ПКМ — поставить/снять флаг
  H — подсказка
  A — применить подсказку
  N — новая игра
  T — trainer on/off
  / — фокус на командной строке

CLI-команды:
  open C4
  flag D7
  hint
  why
  apply
  new
  mode easy
  mode medium
  mode hard
  trainer on
  trainer off
  noguess on
  noguess off
  help

Что именно обучает:
  1. Ищет цифру, с которой проще всего начать.
  2. Показывает формулу: цифра - флаги = сколько мин ещё нужно.
  3. Подсвечивает доказанные безопасные клетки или мины.
  4. В trainer mode не даёт случайно поставить неверный флаг и не завершает игру смертельным кликом.
  5. По умолчанию пытается генерировать поле, решаемое базовыми правилами без угадывания.
