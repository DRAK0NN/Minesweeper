# MINESWEEPER://TRAINER

Веб-тренажер Сапера с терминальным интерфейсом. Работает локально в браузере без подключения к интернету.

**Онлайн-версия:** [drak0nn.github.io/Minesweeper](https://drak0nn.github.io/Minesweeper/)

## Что умеет тренажер

1. Генерирует поля без угадывания (решаются только базовой логикой).
2. Находит цифру, с которой проще всего начать разбор.
3. Показывает расчет по формуле: `цифра - флаги = сколько мин осталось`.
4. Подсвечивает доказанные безопасные клетки и мины.
5. В режиме тренера блокирует случайные ошибки (не дает поставить неверный флаг или подорваться).
6. При проигрыше запускает пошаговый разбор ошибки на поле.

## Управление

* **ЛКМ** - открыть клетку
* **ПКМ** - поставить или снять флаг
* **H** - показать подсказку
* **A** - применить подсказку
* **N** - новая игра
* **T** - включить или выключить режим тренера
* **R** - повторить разбор ошибки после поражения
* **/** - перейти к вводу команд

## Терминальные команды

```text
open C4       открыть клетку C4
flag D7       поставить или снять флаг на D7
hint          найти самую простую цифру для хода
apply         выполнить действие из подсказки
why           повторить разбор ошибки
new           начать новую партию
mode easy     сложность: easy, medium или hard
trainer on    включить или выключить страховку (on / off)
help          список команд
```

## Локальный запуск

Открыть напрямую (Linux):

```bash
xdg-open index.html
```

Или запустить через локальный HTTP-сервер:

```bash
python3 -m http.server 8080
# затем открыть в браузере http://localhost:8080
```
